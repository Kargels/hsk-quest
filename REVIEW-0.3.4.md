# HSK Quest 0.3.4 — к просмотру

Изменения локальные, без commit, push и публикации. Файлы MP3 и имя базы `hsk-quest-v1` не изменены.

## Поведение

- Один делегированный обработчик кликов вместо повторных подписок при render().
- Запись завершается только на `IDBTransaction.oncomplete`. Кандидат состояния становится текущим лишь после успешной транзакции. При отказе сохраняются прежний экран, выбранный ответ и данные; действие можно повторить.
- На время записи кнопки блокируются. Повторные клики не создают дополнительные записи.
- Перед записью текущий снимок сравнивается с базой внутри той же транзакции. При конфликте вкладок запись отклоняется с просьбой обновить страницу.
- При запуске проверяются версия, структура, курсор, ссылки на слова, варианты, ответы и счётчики. Старые визуальные ответы без questionKey/mode нормализуются в памяти. Запуск ничего не записывает в базу.
- Повреждённое или неизвестное состояние блокирует продолжение и предлагает выгрузку оригинала. Автоматического удаления или частичного восстановления нет.
- Аудио останавливается при смене экрана/задания и pagehide. Запоздавшие ошибки остановленного проигрывателя игнорируются.
- Повторные попытки сохраняются независимо, с новым ID. Уникальное занятие пока означает дневную тренировку: `daily:YYYY-MM-DD`. Повторы наследуют lessonKey. Старые записи без ключа учитываются по дате. Это не модель будущего курса из 40 разных уроков.
- Завершение хранит отдельный completedDay. Результат показывает последнюю попытку, история — все попытки.
- Сброс требует подтверждения и использует ту же атомарную запись; базу не удаляет. При отказе транзакции прежний прогресс остаётся.

## Автоматические проверки

Запуск без установки зависимостей:

```sh
node --test tests/critical.test.cjs
```

14 тестов: навигация; завершение/отмена транзакции; отказ и повтор сохранения; блокировка двойных кликов; две попытки одного занятия; старый формат; восстановление проверенного ответа; повреждённые данные; отказ перехода/завершения; подтверждение и отказ сброса; конфликт вкладок; завершение на следующий день; аудио; наличие MP3.

Тесты выполняют реальный inline-скрипт в Node VM с имитацией DOM, Audio и жизненного цикла IndexedDB. Они не обращаются к пользовательской базе и не заменяют тестирование браузерных движков.

## Ограничения перед публикацией

- Программа всё ещё демонстрационная: 10 слов, без курса из 40 уроков.
- Нет импорта JSON, синхронизации и гарантированного офлайн-режима.
- Повреждённые данные требуют отдельного восстановления из выгруженного оригинала.
- Между вкладками нет живого обновления; конфликт требует reload. Старую уже открытую версию 0.3.2 нужно закрыть: её код не знает о новой защите записи.
- Состояние по-прежнему хранится целиком под `state/main`; масштабирование истории отложено.
- Счётчики слов включают незавершённую попытку, общая точность — завершённые попытки.
- Нужна ручная проверка на целевых iPhone/Android, включая MP3 и прерывание страницы во время записи. Качество произношения не оценивалось.
- Для сохранения доступа к прежнему прогрессу публиковать на прежнем origin (протокол, домен, порт). Перед публикацией рекомендуется выгрузить JSON штатной кнопкой.
