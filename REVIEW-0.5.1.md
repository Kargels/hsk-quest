# HSK Quest v0.5.1 — проверка релиза

31 октября 2026. Отчёт проверок перед публикацией релиза.

В основное упражнение интегрирован утверждённый SVG-стиль «Имитация кисти · 8–20 px». Рабочий `hanzi-brush.js` проверяется фиксированной SHA-256 `ef7188b1cef4651aa8a15c2a61bf551f3a17e5420be282fd5d4e13880a7691c2`. Зависимость теста от экспериментального прототипа устранена: ожидаемая сумма зафиксирована в тесте, а не вычисляется из проверяемого файла. Папка `prototypes/` не входит в релиз. Скорость задаёт основную ширину 8–20 CSS px; начало и кончик дополнительно сужаются. Цвет #333 сохранён.

Отдельный визуальный адаптер использует пассивные слушатели тех же событий, что Hanzi Writer, не останавливает события и не меняет точки распознавателя. Стандартная пользовательская линия скрыта. Принятые эталонные черты, подсказки и образец отображает прежний Hanzi Writer 3.7.3.

При блокировке поля слой очищается: это включает обработку результата, сохранение, подсказки и перезапуск. При отмене касания незавершённая траектория отменяется и quiz возобновляется с текущей черты без изменения сохранённой попытки. При смене экрана iframe удаляется вместе с обработчиками. Алгоритмы оценки и хранения не менялись.

Проверки:
- 61/61 автоматических Node-тестов (включая фиксированную контрольную сумму, диапазон ширины, плавность контура, заострение и короткие движения). Проверены также в чистой копии файлов релиза без prototypes/.
- 16 браузерных сценариев основного упражнения; добавлены проверки слоя при движении, отсутствия двойной линии, очистки после результата и отмены касания без изменения попытки.
- UX-прогон на 320 и 390 px: иерархия, отмена просмотра образца, отказ сохранения, показ образца, полная анимация, связанная учебная попытка.
- Правильные/ошибочные движения, несколько последовательных черт, завершение, подсказки, «Заново», перезагрузка и отдельные результаты проверены в чистых тестовых браузерных контекстах.
- git diff --check и git diff --cached --check: без ошибок.
- Код IndexedDB и формат состояния не изменены; тесты сохранности старых результатов и обработки ошибок записи проходят. Пользовательская база не очищалась.

PRODUCT.md обновлён. Для обхода старого кэша ресурсы поля имеют версию v0.5.1.

Ограничения: физический iPhone Safari пока не проверен; Chrome с touch-эмуляцией не заменяет устройство. Сужение — визуальная имитация, не оценка каллиграфии. Селектор скрытия исходной линии зависит от SVG-структуры закреплённой версии Hanzi Writer.

Для локальной проверки запустите HTTP-сервер из корня репозитория. Факт публикации и хеш релизного коммита сообщаются после завершения GitHub Pages.
